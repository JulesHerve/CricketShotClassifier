# SD card contents

Copy this `czero/` folder to the ROOT of a FAT32 microSD card.

- `ir/`      learned IR buttons (`.ir`) - one example included
- `badusb/`  USB keyboard macros (`.txt`) - one example included
- `subghz/`  saved Sub-GHz captures (`.sub`) - created when you save one
- `nfc/`     tag identity log (`tags.csv`) - created when you save one

The firmware creates any missing folders on first boot.
